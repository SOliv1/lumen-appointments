## Lumen Appointments

A calm, modern workspace for coordinated care.
Lumen Appointment Planner is a fully‑designed front‑end environment for managing patient appointments, clinician workflows, and administrative coordination. It provides a clear, structured interface that supports real‑world care pathways while maintaining a gentle, seasonal design language.
