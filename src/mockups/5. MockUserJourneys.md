 User Journeys (Mock)

## Journey 1 — Add a Clinician
1. User opens Clinicians page.
2. Enters name, role, specialty, contact.
3. Optionally enters GMC/NMC/HCPC.
4. Clicks Add Clinician.
5. Clinician appears in list with UUID.

## Journey 2 — Book an Appointment
1. User opens Appointments.
2. Selects patient.
3. Selects clinician.
4. Chooses date/time.
5. 5. Enters reason.
6. Clicks Add Appointment.
7. Appointment appears in list.

## Journey 3 — Add Availability
1. User opens Availability.
2. Selects clinician.
3. Chooses date/time.
4. Sets status.
5. Clicks Add Slot.

## Journey 4 — Update a Clinician
1. User clicks Update next to clinician.
2. Form pre-fills.
3. 3. User edits details.
4. Clicks Update Clinician.

## Journey 5 — Add a Contact
1. User opens Contacts.
2. Enters name, relationship, phone.
3. Clicks Add Contact.
4. Contact appears in list.
