# Serene-Care-Sync User Journeys (Mock)

## Journey 1 - Add a Clinician
1. User opens Clinicians page.
2. Enters name, role, specialty and contact.
3. Optionally enters GMC/NMC/HCPC registration.
4. Clicks Add Clinician.
5. Clinician appears in Clinical Team with Update and Delete actions.

## Journey 2 - Book a Safe Appointment
1. User opens Appointments page.
2. Selects patient.
3. Selects clinician.
4. Chooses date and stable time-slot dropdown.
5. Enters appointment reason.
6. Appointment Safety Panel checks contact details, availability, notice period, conflicts and reason.
7. If all checks pass, user clicks Book Appointment.
8. Appointment appears in Appointment Schedule with communication status and reminder plan.

## Journey 3 - Handle Short Notice
1. User selects an appointment date with less than the required notice period.
2. Safety Panel shows a short-notice warning.
3. User reviews suggested later slots.
4. User either chooses a safer later slot or records a short-notice reason.
5. System stores the reason with the appointment change log.

## Journey 4 - Prevent a Booking Conflict
1. User selects a clinician and time already used by another appointment.
2. Safety Panel warns that the clinician is already booked.
3. User sees nearest safe alternative slots.
4. User chooses a safe slot.
5. Appointment can now be saved.

## Journey 5 - Update an Appointment
1. User clicks Update next to an appointment.
2. Form pre-fills with appointment details.
3. User changes date, time, clinician or reason.
4. Safety Panel reruns checks.
5. User selects a change reason.
6. User clicks Save Appointment.
7. Appointment schedule updates and the communication status returns to Needs follow-up if patient notice is required.

## Journey 6 - Cancel and Release a Slot
1. User selects Delete or Release slot on an appointment.
2. System asks for the change reason.
3. User chooses Patient requested change, Clinician unavailable, Admin correction or another reason.
4. User chooses Cancel and release slot.
5. Slot becomes available.
6. Short Notice List displays patients who can attend quickly.
7. User can offer the released slot to a selected patient.

## Journey 7 - Add Availability
1. User opens Availability page.
2. Selects clinician.
3. Chooses date.
4. Selects start time and end time from stable dropdowns.
5. Selects status.
6. Clicks Add Availability.
7. Slot appears in Availability Board with Update and Delete actions.

## Journey 8 - Update Patient Details Before Notice
1. User starts booking appointment.
2. Safety Panel shows patient contact is missing or incomplete.
3. User opens Patients page.
4. Clicks Update next to patient.
5. Adds contact details or care notes.
6. Returns to Appointments page and the readiness check passes.
